I explore machine learning applications across athletic and academic performance — using data to model how humans train, learn, and improve. Each project follows a full ML pipeline: data engineering, preprocessing, model selection, validation, and interpretation.

01 / 03
100m Sprint Time Predictor
A Random Forest regression model predicting 100m sprint times from athlete training, lifestyle, and physical metrics. Dataset: 150 synthetic athlete profiles grounded in sports science research. Methodology: train/test split, Random Forest regression, MAE validation.
WHY THIS MATTERS
Quantifying how lifestyle factors affect athletic output gives athletes and coaches a data-driven foundation for performance decisions — beyond intuition alone.
KEY INSIGHT
Sleep quality and reaction time were the strongest predictors of sprint performance — outweighing raw strength metrics. Analysis stage took longer than the coding itself.

02 / 03
Student Grade Predictor
A Random Forest regression model predicting upcoming test grades from lifestyle and academic inputs. Dataset: 300 synthetic student profiles with realistic academic relationships. Methodology: categorical encoding, train/test split, Random Forest regression, MAE validation.
WHY THIS MATTERS
Understanding which lifestyle factors most influence academic performance gives students a data-backed framework for improving results — not just generic study advice.
KEY INSIGHT
Replacing an AI-generated dataset with a properly engineered one dropped MAE from 16.41 to 4.15 — demonstrating that data quality matters far more than model complexity.
